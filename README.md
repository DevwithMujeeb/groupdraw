# GroupDraw

A 3D website that randomly assigns students to groups for our class. Students sign in with their school email, enter their matric number, and press one button to get their group and role. One leader is picked at random in every group.

Live site: https://uthman-lab.expadox.com/groupdraw/

## Features

* Sign in with Google using a school email only
* Fair random draw, with one leader per group
* Group sizes adjust to the class (for 52 students, groups 1 and 10 have 6 members and the rest have 5)
* Admin page with the class list and a CSV download
* 3D background with flying quotes that the admin can edit
* WhatsApp link for each group

## Built with

HTML, CSS and JavaScript, three.js for the 3D scene, Firebase for sign in and storage, and GitHub Pages for hosting.
